# Caves Revamp — Levels 9–17

Status: **not planned yet**  
Parent: [Feature plans](README.md)

The current section-based generator remains in use for caves until this plan is
written.

## Planned scope

- natural cave shapes instead of reused room sections
- underground rivers, chasms and bridges
- mines, shafts and collapsed tunnels
- fungus forests and subterranean lakes
- cave-specific creatures, hazards and loot
- cave-specific palette and lighting

## Open topics

- how much of the recovered 10×40 section generator should be retained
- whether caves should use a cellular-automata generator or hand-authored set pieces
- how light sources and darkness interact with FOV
